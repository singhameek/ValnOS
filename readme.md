ValnOS is a web based desktop OS, built in HTML, CSS, and JavaScript.

Features:
- Draggable and closable windows
- Auto-focus between multiple windows
- Live top bar with time and date that pulls the information from the device running the webOS
- Desktop Icons
- Web Browser
- Notes App
- Calculator
- Music App, playback continues when app is closed inside ValnOS
- Audio feedback on user input

Extra feature beyond guide: date implementation (WebOS 1, Ship #1)
Extra features beyond WebOS 1: Music app, taskbar, audio feedback, 

I chose to make the background a Red Bull F1 car bc I love F1. The majority of the dev process was simply following the guide, but I implemented a different app (the web browser), and decided to go with a transparent look because I think that Microsoft's second biggest mistake was getting rid of their Aero design scheme, and their biggest was Windows 8. I chose these icons for the apps because they resemble Linux Mint's standard icons in a way, and Mint was my first Linux Distro
